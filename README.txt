للنشر على GitHub Pages (الأسهل):
  ارفع ملف index.html فقط إلى جذر المستودع (stock)، وهو يكفي لتشغيل الموقع.
  ملف .nojekyll اختياري.
  بعد الرفع انتظر دقيقة ثم حدّث الصفحة بقوة (Ctrl+Shift+R).
  للتصوير: اضغط زر ⚙️ داخل التطبيق والصق مفتاح Anthropic API.

مجلد source (للمطورين، لا ترفعه إن لم تحتجه):
  pages-app.jsx     كود التطبيق الذي بُني منه index.html
  server-version/   نسخة كاملة بسيرفر يخفي المفتاح (npm install ثم npm run dev)
