# مخزون المحل

## التشغيل
1. ثبّت Node.js (الإصدار 18 أو أحدث).
2. انسخ `.env.example` إلى `.env` وضع فيه مفتاح Anthropic API.
3. من داخل المجلد:
   npm install
   npm run dev
4. افتح الرابط الذي يظهر (مثل http://localhost:5173). للفتح من الموبايل على نفس الشبكة استخدم عنوان الكمبيوتر بدل localhost.

## التشغيل النهائي
npm start   ← يبني التطبيق ويقدّمه على المنفذ 3001

## ملاحظات
- الكميات تُحفظ في متصفح الجهاز (localStorage).
- المفتاح يبقى في السيرفر فقط ولا يصل للمتصفح.
- لتثبيته كتطبيق على الموبايل: افتحه في المتصفح ثم «إضافة إلى الشاشة الرئيسية».
  (كاميرا الموبايل تتطلب https أو localhost، فاستضفه على خدمة تدعم https مثل Render أو Railway.)
